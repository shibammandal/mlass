# Machine Learning Assignments

This repository contains Jupyter Notebooks (`.ipynb`) extracted from the assignment documents.

## Repository Structure

### 📁 `Lab_Assignments_Set_2_3/`
- **`Assignment_2.1_Logistic_Regression.ipynb`**: Logistic Regression classification on `Social_Network_Ads.csv` with feature scaling, confusion matrix, accuracy score, and decision boundary visualization.
- **`Assignment_2.2_KNN.ipynb`**: K-Nearest Neighbors ($k=5$, Minkowski metric) on `Social_Network_Ads.csv` with decision boundary visualization.
- **`Assignment_3.1_Hierarchical_Clustering.ipynb`**: Agglomerative Hierarchical Clustering (Ward's linkage) on `Mall_Customers.csv` with dendrogram and cluster scatter plot.
- **`Assignment_3.2_KMeans_Clustering.ipynb`**: K-Means Clustering on `Mall_Customers.csv` with Elbow Method (WCSS) and cluster centroids plot.

---

### 📁 `Regression_Assignments/`
- **`Assignment_1a_Linear_Regression_CO2.ipynb`**: Linear Regression predicting vehicle $CO_2$ emissions on `fuel_consumption_dataset.csv` with MAE, MSE, RMSE, $R^2$, and Actual vs. Predicted plot.
- **`Assignment_1b_Linear_Regression_CarPrice.ipynb`**: Linear Regression predicting used car selling prices on `used_cars_dataset.csv` with categorical one-hot encoding, error metrics, and Actual vs. Predicted plot.
- **`Assignment_2_Ridge_Lasso_Regression.ipynb`**: Ridge (L2) and Lasso (L1) Regularization with 5-fold `GridSearchCV` hyperparameter tuning on `housing_price_dataset.csv`.
- **`Assignment_3_Gradient_Descent_Salary.ipynb`**: Linear Regression using Gradient Descent implemented from scratch (with learning rate search and hypothesis function evolution across epochs) on `salary_dataset.csv`.
- **`Assignment_4_NonLinear_Regression_ChinaGDP.ipynb`**: Non-linear regression fitting a Sigmoidal / Logistic growth curve via `scipy.optimize.curve_fit` on `china_gdp.csv`.
- **`Assignment_5_Logistic_Regression_Cancer.ipynb`**: Logistic Regression classifying benign vs. malignant tumor on `samples_cancer.csv` with Confusion Matrix heatmap and ROC/AUC curve analysis.
